# Food + Calorie Lookup

BIT4443 Deep Learning Group Project — a Streamlit app that identifies a food photo (12 dish classes)
and estimates its calorie content, using a fine-tuned EfficientNet-B0.

## Setup

1. **Train the model (one-time):** open `train_food_classifier.ipynb` in Google Colab
   (`Runtime → Change runtime type → GPU`) and run all cells. This downloads Food-101, fine-tunes
   EfficientNet-B0, and downloads `food_classifier.pth` + `class_names.json` to your computer.
   Takes roughly 20–40 minutes on a free Colab GPU.

2. **Assemble the app folder:** put `app.py`, `requirements.txt`, `food_classifier.pth`, and
   `class_names.json` in the same folder.

3. **Install dependencies:**
   ```
   pip install -r requirements.txt
   ```

4. **Run the app:**
   ```
   streamlit run app.py
   ```

## Files

| File | Purpose |
|---|---|
| `train_food_classifier.ipynb` | Trains the model — run this in Colab first |
| `app.py` | The Streamlit app |
| `requirements.txt` | Python dependencies for the app |
| `food_classifier.pth`, `class_names.json` | Generated by the notebook, required by the app (not included — you generate these by running the notebook) |

## Classes

Pizza, Sushi, Hamburger, Ramen, Fried Rice, Ice Cream, Steak, Caesar Salad, Chicken Wings,
French Fries, Donuts, Pad Thai
